# Third-party content in the repository

An inventory of code and data in this repository that came from, or quotes,
somebody else's work, with the licence the repository itself records for each
source, and the risk. It is an audit, not a remediation: nothing was moved,
deleted or rewritten when it was written (2026-10-23, at `33e7e5a`).

Licences below are **as recorded in this repository** (`tools/gold/repos.json`,
`tools/gold/benchmarks.json`, `tools/ground_truth/fetch_gt.sh`). Nothing was
fetched to check them. "Unknown" means the repository records no licence for
that source. `NOASSERTION` is what the GitHub API returned when
`repos.json` was written, and means GitHub could not identify the licence; it
is not a licence.

Third-party *software* Arbiter depends on or invokes (PyYAML, the analyzers,
the vendored graph viewer) is inventoried separately in
[NOTICE.md](../NOTICE.md).

## Summary of risks

1. **Label files quote code from GPL-licensed benchmarks.** The model labels'
   free-text `reason` and `votes` fields quote fragments of the code they
   judged. For the OWASP Benchmark (Java: GPL-2.0; Python: GPL-3.0), 535 quoted
   fragments of 20 characters or more appear verbatim in the benchmark source
   (about 12,900 characters in all; the longest is 47 characters). Fragments
   that short are probably not a substantial copy, but this repository is
   Apache-2.0 and the question has not been reviewed. **Highest-priority item
   for counsel.**
2. **Label files quote code from repositories with no determined licence.**
   `py-celery`, `py-cryptography`, `ruby-rack` and `ruby-rubygems` are recorded
   as `NOASSERTION`; the three CVE-fix sources (`mar10/wsgidav`, `ruby/rdoc`,
   `danger/danger-js`) have no licence recorded at all.
3. **Label files quote code from permissively licensed repositories** (MIT,
   BSD-3-Clause, Apache-2.0): about 1,250 verbatim fragments, none longer
   than 75 characters. These licences generally require keeping a copyright
   and licence notice with copies; whether fragments this size trigger that is
   for counsel.
4. **Labels are model output describing third-party code.** Even where they do
   not quote, the reasons paraphrase specific functions in named files of
   named projects. That is commentary, which is lower risk than copying, but
   it is published permanently in git history.
5. **AI-generated fixtures** (`fixtures/ai-corpus*`) are Claude output with no
   licence statement. Their copyright status is an open question (see
   [ai-assisted-development.md](ai-assisted-development.md)).
6. Low: commit subjects and short evidence strings from training-corpus
   repositories in `training/fix-pairs.json`; and absolute local paths
   (`~/wt/corpus-gt/...`) in `tools/gold/labels/cve-suspects.json`.

No third-party source file was found committed whole. The fixture code was
checked against the local OWASP Benchmark checkouts; the only shared lines
are Servlet boilerplate (see [Fixtures](#fixtures)).

## Options

For the owner and counsel to choose from; none has been applied.

1. **Strip quotations from label text.** Keep the label, the rule, the path,
   the line and `excerpt_sha256`; replace `reason` and `votes` text with a
   short code-free summary, or drop it. The ledger needs only the counts.
   Where a reason must be kept for audit, store it outside the public
   repository.
2. **Store fingerprints and line references, not text.** The records already
   carry `excerpt_sha256`, path and line at a pinned commit. Anyone with the
   pinned checkout can recreate the excerpt, so the excerpt and the quotes
   need not be published.
3. **Keep labels out of the public repository.** Publish the derived ledger
   (`packs/precision.json`) and the method, and keep the raw label files in a
   private repository or release artefact. Costs reproducibility for outside
   readers.
4. **Exclude GPL and unknown-licence sources first.** If only some labels are
   changed, start with OWASP Benchmark (GPL), the `NOASSERTION` repositories
   and the CVE-fix sources.
5. **Add attribution** for the permissively licensed sources in `NOTICE.md`,
   if counsel finds the fragments need it.
6. **History.** Every option above changes the current tree only. Quotations
   already committed stay in git history unless history is rewritten, which
   would break every published commit hash. Counsel should say whether that
   matters.
7. **Record licences for the training corpus and CVE sources**, from each
   project's own `LICENSE` file at the pinned commit, so the next audit is not
   "unknown".

## How the figures were measured

- Record counts: every non-blank line of each `.jsonl` / `.jsonl.gz` file.
- "Quoted fragments": spans between backticks of 20 or more characters in a
  record's `reason`, `votes` and `definitions_shown` strings.
- "Verbatim in source": the fragment occurs as an exact substring of the
  concatenated source files (`.java`, `.py`, `.rb`, `.go`, `.ts`, `.js`,
  config and docs) of the local, read-only checkouts in `~/wt/corpus-gold/`
  and `~/wt/corpus-gt/juliet-java` that the labels were produced from. No
  network access was used. Exact matching undercounts quotes the model
  reformatted.
- Fixture overlap: lines of 40 or more characters (stripped) in
  `fixtures/planted/` compared with the OWASP Benchmark checkouts.
