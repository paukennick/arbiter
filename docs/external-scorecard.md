## Matching

- **owasp**: one unit per expectedresults row; flagged when an active finding in the case's file carries the case's CWE or a benchmark alias (tools/gold/benchmarks.json), the rule of gold_benchmark.score_recall. Labels are the benchmark's own.
- **juliet-java**: Arbiter-defined units: files sharing a case stem form one case; each case is a vulnerable unit (matching-CWE finding inside bad code, benchmarks_gt.juliet_side) and a safe unit (inside good* code). Findings outside any bad/good method are counted unassessed.
- **cve-fix-pairs**: Arbiter-defined units: per GitHub advisory fix pair, a vulnerable unit (matching-CWE finding within 2 lines of a hunk the fix changed, vulnerable side) and a safe unit (same window, fixed side); project-level rules excluded; stratum is the CWE the pair was selected for.

python tools/ground_truth/external_scorecard.py --aggregate-only --corpus ~/wt/corpus-gold --gt ~/wt/corpus-gt --out docs/external-scorecard.json --markdown docs/external-scorecard.md
